# 给大家分享一个我自己写的工具：扒稿机

> 一条命令，把**视频变成文案**、把**链接变成原片**。
> 免费、开源、不注册、不要 API Key。

项目地址：**https://github.com/hope0719/bagaoji**

---

## 一、先说它解决什么问题

做短视频拆解、仿写、二创的同学都懂，前面永远卡着两步纯体力活：

1. **把视频里的口播抄成文字** —— 手动听打，10 分钟的视频要花 40 分钟；
2. **把原片存到本地** —— 平台不给下载按钮，或者下下来带水印。

以前的办法只有两个：要么买按分钟计费的语音转写 API，要么去在线解析站一条条贴、还限次数。

**扒稿机把这两件事合成了一条命令：**

```bash
python3 -m bagaoji "小红书链接" --download --out ~/Desktop/扒稿
```

回车之后，文案和素材一起落到你桌面上。

## 二、它能干什么

| 能力 | 说明 |
|---|---|
| 📝 **图文笔记直接出正文** | 不用转写、不排队、不消耗额度，原文直接取出来 |
| 🖼️ **图集原图批量下载** | 一次把 9 张 18 张全下下来，按顺序命名，最高画质 |
| 🎬 **视频原片下载** | 多清晰度可选，无水印 |
| 📋 **元信息一起拿** | 标题、作者、发布时间、点赞收藏评论数 |
| 🔍 **支持整段分享口令** | 直接从 App 复制那一整段话丢进来，自动识别链接 |
| 📚 **支持多条批量** | 一整个 txt 文件的链接，一次跑完 |

**目前开箱可用的是小红书**（图文 + 图集 + 视频全家桶）。
抖音、B站、快手、视频号等其他平台，我在项目里留了扩展接口，会写代码的同学可以自己加，也欢迎直接把你在用的网站发给我。

## 三、三分钟装好

### 第 0 步：确认你有 Python

打开终端（Mac 是「终端」，Windows 是「PowerShell」），输入：

**Mac：**
```bash
python3 --version
```

**Windows：**
```bash
python --version
```

看到 `Python 3.9` 或更高的版本号就行。

- Mac：**系统自带，直接能跑**，不用装任何东西；
- Windows：如果没有，去 [python.org](https://www.python.org/downloads/) 下载安装包，**安装时务必勾选「Add Python to PATH」**（这一步不勾，后面命令会找不到）。

### 第 1 步：把项目下载下来

**方式 A（推荐，如果你会用命令行）：**

```bash
git clone https://github.com/hope0719/bagaoji.git
cd bagaoji
```

**方式 B（不想碰命令行）：**

打开 https://github.com/hope0719/bagaoji ，点绿色的 `Code` 按钮 → `Download ZIP` → 解压到你顺手的位置。

[此处配图：GitHub 页面上 Code 按钮的位置]

### 第 2 步：验证装好了

在项目文件夹里执行：

```bash
python3 -m bagaoji --list      # Windows 用户把 python3 换成 python
```

看到类似这样的输出，就成功了：

```
已注册适配器：
  xhs      小红书   免登录  短链 → 笔记页 → 内嵌 JSON...
```

> 💡 **小技巧**：不想手打文件夹路径？
> 在终端里先输入 `cd `（注意后面有个空格），然后把项目文件夹**直接拖进终端窗口**，路径会自动填上，回车即可。

> ⚠️ **一个避坑提醒**：项目文件夹和输出目录**尽量放在纯英文路径下**。
> 个别系统对中文路径处理不稳定，放在 `~/Desktop/bagaoji` 这种路径最稳。

## 四、四条命令就够用

### ① 只想拿文案

```bash
python3 -m bagaoji "你的链接"
```

图文笔记直接把正文打出来。视频笔记会告诉你需要自己转写（原因见下面第五条）。

### ② 文案 + 素材一起要（最常用）

```bash
python3 -m bagaoji --download "你的链接" --out ~/Desktop/扒稿
```

会在桌面建一个「扒稿」文件夹，里面一条笔记一个 Markdown 文档，媒体文件就在旁边。

### ③ 只要最高画质的原图

```bash
python3 -m bagaoji --download --only image --img-mode raw "你的链接"
```

### ④ 一次处理很多条

把链接一行一条存成 `urls.txt`，然后：

```bash
cat urls.txt | python3 -m bagaoji --download --out ~/Desktop/扒稿
```

## 五、链接怎么拿？（这一步最容易翻车）

**必须从小红书 App 里点「分享 → 复制链接」拿到的链接。**

直接把那一整段分享文字丢进来也行，工具会自动识别：

```
77 这篇笔记写得真好，快来看看！😆 https://xhslink.cn/o/xxxxxx，复制本条信息，打开【小红书】App查看精彩内容！
```

⚠️ **千万不要手动删掉链接问号后面的那一串参数**。那串 `xsec_token` 不是统计数据，是**必需的**——删掉之后页面会返回一个空壳，什么内容都没有。这是最常见的失败原因。

## 六、常见问题

| 现象 | 原因与解决 |
|---|---|
| 提示 `command not found: python3` | Windows 请改用 `python`；Mac 确认系统版本较新，或装一次 Xcode 命令行工具 |
| 提示 `No module named bagaoji` | 你没在**项目文件夹里面**执行命令。先 `cd` 进去再跑 |
| 解析出来是空的 / 没有内容 | 链接被手动改过，`xsec_token` 丢了。重新去 App 里复制一次 |
| 下载的文件打不开 | 直链有时效（几小时到几天）。重新跑一次解析拿新链接 |
| 某个第三方网站提示要登录 | 见下一节 |

## 七、进阶：某些网站提示「请先登录」

我在调研过程中发现一个很有意思的现象：**很多解析站不是技术不行，而是就差一个登录态**——接口都是通的，唯一拦你的是服务端在门口说「未登录」。

这种情况，你只要在浏览器里**正常登录一次**，把 Cookie 交给工具就行：

```bash
python3 -m bagaoji --cookie "你的Cookie" "链接"
```

不想每次都贴，也可以存成一个文件长期用：

```bash
mkdir -p ~/.bagaoji
echo '{"_default": "你的Cookie"}' > ~/.bagaoji/cookies.json
```

对了，随时可以用这条命令看**哪些网站需要登录、登录之后能多得到什么**：

```bash
python3 -m bagaoji --auth
```

> 🔒 **安全提醒**：Cookie 等同于你的登录凭证，**只在自己的电脑上用**，不要发到群里、不要贴到网上。
> 这个工具不上传、不记录、不分享你的任何凭据——代码全部开源，可以自己看。
